# SyntaxWear - E-commerce de Tênis e Sneakers

## Descrição

SyntaxWear é um site de e-commerce dedicado à venda de tênis e sneakers online. O projeto apresenta uma interface moderna e responsiva, com foco em uma experiência de usuário intuitiva. Inclui seções como hero banner, categorias de produtos, produtos em destaque e rodapé com informações de contato.

O site é construído utilizando HTML5 e CSS3, com um design limpo e atrativo, otimizado para dispositivos móveis e desktop.

## Funcionalidades

- **Header responsivo**: Navegação com menu hambúrguer para mobile.
- **Seção Hero**: Banner principal com chamada para ação.
- **Categorias**: Links para categorias como Casual, Esporte, Moderno e Futurista.
- **Produtos**: Exibição de produtos com imagens e descrições.
- **Footer**: Informações de contato e links para redes sociais.

## Tecnologias Utilizadas

- **HTML5**: Estrutura do site.
- **CSS3**: Estilização, incluindo variáveis CSS, flexbox e grid.
- **Google Fonts**: Fonte Ubuntu para tipografia.
- **SVG**: Ícones vetoriais para logo e elementos de navegação.

## Como Executar o Projeto

1. **Clone o repositório** (se aplicável):
   ```
   git clone <url-do-repositorio>
   ```

2. **Abra o arquivo `index.html`** no seu navegador preferido:
   - Navegue até a pasta do projeto.
   - Clique duas vezes em `index.html` ou arraste o arquivo para uma janela do navegador.

O site será carregado e você poderá navegar pelas seções.

## Responsividade

O site é totalmente responsivo, adaptando-se a diferentes tamanhos de tela:
- **Desktop**: Layout completo com navegação horizontal.
- **Mobile**: Menu hambúrguer e ajustes de layout para telas menores.
